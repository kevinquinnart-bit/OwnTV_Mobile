# KueTV (phone and tablet)

Kevin's IPTV player for Android phones and tablets. It provides no channels or content; you bring your
own legally accessible sources.

Download the latest phone app: https://github.com/kevinquinnart-bit/OwnTV_Mobile/releases/latest/download/OwnTV-Mobile.apk
